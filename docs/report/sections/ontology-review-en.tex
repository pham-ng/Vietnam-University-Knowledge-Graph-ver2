\subsection{Assessment: standards-based, but not semantically complete}
The design is credible for an educational knowledge-graph prototype. It separates people,
organizations and geography; distinguishes membership, branch affiliation, ownership and
state oversight; reuses external vocabularies; and combines inference with explicit SHACL
validation. The two-layer validation design is appropriate because open-world entailment
does not implement closed-world data entry rules. Avoiding an area-property alignment with
incompatible units is also a good design decision.

However, valid Turtle and passing tests do not certify the domain model. Table~\ref{tab:design-review}
identifies semantic decisions still requiring revision or evidence. These findings concern
what axioms entail, even when the current snapshot produces no contradiction. They are
not silently presented as already repaired.

These issues have different severities. Over-strong vocabulary alignments can assert facts
not supported by their source relation, whereas missing temporal qualifiers mainly limit
which questions are answerable. A migration should preserve old URIs, update affected
queries and shapes, regenerate the graph, and add negative competency tests. Merely editing
a diagram or replacing labels would not correct the underlying semantics.

\subsection{Competency questions as a design contract}
Useful design tests should cover both answers and prohibited conclusions:
\begin{enumerate}
\item Which institutions are members of a university, and which are branches? Check that
the two relations remain distinct after materialization.
\item Which body directly governs a school, and which ministry is an indirect superior?
The current \term{governedBy} closure does not preserve this distinction in the predicate.
\item Which organization offers a program, and which major does that offering concern?
The current chain answers this for the illustrative single-provider program model.
\item Where is an institution under the chosen administrative crosswalk, and where was
it located at a historical date? Only the first question is supported reliably by the model.
\item Who held a leadership role on a specified date, and how many students were enrolled
in a specified year? The current unqualified edges and counts cannot establish these answers.
\end{enumerate}

Thus the verdict is \emph{standards-based and useful, with significant semantic and temporal
limitations}, not ``fully standardized'' or ``formally certified OWL 2 RL.'' The evaluation
does not claim a formal OWL 2 DL profile check either. Rule-engine execution, syntax parsing,
profile membership and domain correctness are separate questions.
